# Request

Turn the "grill me, then build" method into a repo called Feature Forge, working like AuthorForge: enter a request, a button starts a grill session in the Agent Manager chat panel, the plan is saved as .md, every feature plan is a library item with a checklist of what is done and what is not, and extra grill sessions can be started on each item from the UI.
